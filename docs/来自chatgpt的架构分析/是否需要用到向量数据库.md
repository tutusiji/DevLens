# 一、核心问题先回答：要不要向量数据库？

👉 **结论：必须要，而且是核心基础设施**

原因不是“为了AI”，而是因为：

### 你要解决的是 3 个问题：

### 1️⃣ 代码语义检索（RAG）

- “这个函数在哪里被用？”

- “这个模块负责什么？”

- “这个人改的代码主要影响什么领域？”

👉 必须 embedding + vector search

---

### 2️⃣ 跨文件理解（Graph + Semantic）

- 一个 PR 改了 20 个文件

- 你要理解：
  
  - 依赖链
  
  - 调用链
  
  - 影响范围

👉 纯 AST 不够，必须语义增强

---

### 3️⃣ 开发者能力建模

你不是在分析代码，而是在分析：

> “这个人长期在写什么类型的代码？”

例如：

- 偏业务

- 偏底层

- 偏架构

- 偏修 bug

👉 这个必须靠 embedding 聚类

# 三、代码文档生成（DeepWiki那一层）

### pipeline：

1. Git clone

2. AST 解析（tree-sitter）

   - 模块说明
   
   - 调用关系
