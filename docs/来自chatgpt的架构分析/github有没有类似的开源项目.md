有，而且已经有不少项目在“你这个方向的不同子问题上”做得不错。但需要明确一点：**目前没有一个开源项目能完整覆盖你说的“AI审查 + 安全评估 + Git行为建模 + 人才画像 + 团队模型”这一整套闭环**——基本都是“单点能力”。

我帮你筛了一批**最接近你目标体系的开源项目（按能力分类）**，你可以直接组合成你的系统底座：

---

# 一、AI Code Review / 代码审查（最接近你的一部分）

## 1. CodeRabbit

- GitHub App

- 自动 review PR（基于 LLM）

- 评论质量比较高

👉 特点：

- 能直接接入 PR 流程

- 类似“AI reviewer 同事”

👉 不足：

- 不做开发者建模

- 不分析 Git 行为

---

## 2. ReviewGPT

- 开源 AI 代码审查工具

- 支持 PR diff 分析

👉 适合：

- 作为你 AI review 引擎的 baseline

---

## 3. Bito AI

- IDE + PR review

- 类似 Copilot + Review

👉 思路参考价值 > 代码价值

---

# 二、代码质量 / 安全分析（工业级基础设施）

## 4. SonarQube

- 行业标准

- 静态代码质量分析

👉 能提供：

- 技术债

- bug / code smell

- coverage

👉 缺点：

- 不理解“人”

- 不分析 Git 行为

---

## 5. CodeQL

- GitHub 官方安全分析引擎

👉 强项：

- 安全漏洞检测（AST级别）

👉 非常适合接入你系统的“安全评分维度”

---

## 6. Semgrep

- 轻量规则引擎

- 支持安全扫描

👉 优势：

- 可自定义规则（你可以结合AI）

---

# 三、Git 数据分析 / 工程效率（关键）

## 7. GitStats

- 基础 Git 分析

- commit / author / timeline

👉 很基础，但可以作为数据源

---

## 8. Gource

- Git 可视化（代码演化）

👉 主要是展示层思路

---

## 9. GrimoireLab ⭐重点

- Linux 基金会项目

- 专门做开发者行为分析

👉 能做：

- 开发者活跃度

- 贡献分析

- 社区分析

👉 非常接近你“人 + 项目分析”的一部分

---

## 10. DevLake ⭐重点

- Apache 顶级项目

- DevOps 数据整合平台

👉 能力：

- GitHub / Jira / CI 数据整合

- DORA 指标

👉 这是你系统的**数据层最佳参考**

---

# 四、工程效率 & 团队分析（最接近“能力评估”）

## 11. Velocity

（开源替代较少，偏商业）

👉 类似产品：

- LinearB

- Jellyfish

👉 能做：

- 开发效率

- 团队指标

👉 但：  
❌ 不做 AI  
❌ 不做代码语义分析

---

# 五、AI + Repo 分析（新方向）

## 12. Sourcegraph Cody

- AI + 代码库理解

👉 可做：

- 代码语义分析

- 依赖关系理解

👉 很适合你做：  
**架构能力评估（未来方向）**

---

## 13. OpenDevin

- AI 自动写代码

👉 启发点：

- AI 可以模拟“开发者能力”

---

# 六、结论（重点总结）

### ✔ 有的能力：

- AI code review（CodeRabbit / ReviewGPT）

- 代码质量（SonarQube）

- 安全分析（CodeQL）

- Git 数据分析（DevLake / GrimoireLab）

---

### ❌ 没有的能力（你的机会点）：

你提的这几个，目前**几乎没人做完整闭环**：

1. **Git行为 → 能力建模**

2. **AI review → 人才画像**

3. **代码质量 → 个人评分**

4. **团队结构 → 能力推导**

5. **成长曲线（learning curve）**

👉 也就是说：

> 你这个想法 = 现有工具的“上层智能融合层”
