# 开发路线图

## Phase 0: 基础验证（1-2 周）

**目标**: 验证核心技术路径可行

- [ ] Git 数据采集 POC（接入一个真实仓库）
- [ ] tree-sitter 多语言 AST 解析验证
- [ ] LLM 代码审查 Prompt 原型
- [ ] 基础数据库表创建
- [ ] FastAPI 项目骨架

**交付物**: 一个能跑通的 Git 分析 Demo

## Phase 1: MVP（4-6 周）

**目标**: 核心功能可用

### 后端
- [ ] GitLab API 集成（项目发现、数据拉取）
- [ ] Git 行为建模引擎（4 象限全部实现）
- [ ] AI Code Review 引擎（LLM + 静态分析）
- [ ] 基础代码质量评分
- [ ] 身份匹配引擎（邮箱 + 拼音匹配）
- [ ] 开发者能力模型（7 维向量计算）
- [ ] Celery 异步任务 Pipeline

### 前端
- [ ] 项目接入页面（URL + Token 输入）
- [ ] 分析进度展示（SSE 实时更新）
- [ ] 项目评估 Dashboard
- [ ] 开发者画像页面（雷达图 + 基础信息）
- [ ] 组织架构管理页面

### 基础设施
- [ ] Docker Compose 完整部署
- [ ] PostgreSQL 数据模型
- [ ] Redis 缓存层

**交付物**: 可演示的 MVP 系统

## Phase 2: 深度分析（6-8 周）

**目标**: 完善分析能力

- [ ] 安全评估引擎（漏洞扫描 + AI 审计）
- [ ] 代码图谱生成（tree-sitter + LLM 文档）
- [ ] Qdrant 向量存储 + 语义搜索
- [ ] 团队能力聚合模型
- [ ] 增长曲线 + 趋势分析
- [ ] 代码原创度检测（Embedding 比对）
- [ ] 项目健康度完整评估
- [ ] 前端：代码图谱可视化、团队分析页面

**交付物**: 三体系完整分析能力

## Phase 3: 智能洞察（6-8 周）

**目标**: 交叉分析 + 智能建议

- [ ] 三体系关联洞察引擎
- [ ] 组织风险预警系统
- [ ] 个性化成长建议（LLM 生成）
- [ ] 招聘建议自动生成
- [ ] Bus Factor 可视化
- [ ] 协作网络图
- [ ] 前端：洞察面板、预警通知

**交付物**: 完整的产品功能

## Phase 4: 产品化（持续）

**目标**: 可规模化部署

- [ ] 多租户支持
- [ ] 行业基准对标数据
- [ ] 预测模型（团队调整推演）
- [ ] API 开放平台
- [ ] 性能优化（大规模仓库支持）
- [ ] Kubernetes 部署方案
- [ ] 完善的监控告警

## 技术债务管理

每个 Phase 结束后安排 1 周的 Tech Debt Sprint：
- 重构高复杂度模块
- 补充测试覆盖
- 更新文档
- 优化性能瓶颈
